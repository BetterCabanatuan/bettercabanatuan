# Humiling ng Birth, Marriage o Death Certificate — Lungsod ng Cabanatuan

Nag-iisyu ang City Civil Registry Office ng mga certified copy ng mga rekord ng kapanganakan, kasal at kamatayang nairehistro sa Lungsod ng Cabanatuan. Ang bayad ay {FEE_CRD_COPY} at nakasaad sa Citizen's Charter na {TIME_CRD_TOTAL} ang kabuuang tagal ng pagproseso. Maaaring humiling ng kopya ang may-ari ng rekord, malalapit na kapamilya at ilang iba pang pinahintulutang tao; magkaiba ang dadalhin ng bawat isa bilang patunay ng kanilang karapatan dito.

---

## Saan pupunta

**City Civil Registry Office**
1st Floor, City Hall, Kapitan Pepe Subd. Phase II, Cabanatuan City 3100
Telepono: 0919 081 4548; 044 456 6920

Binabayaran ang bayad sa **Office of the City Treasurer**, na nasa 1st Floor din (0919 089 9849; 044 464 7696).

Ito ang kopya ng lungsod ng rekord. Ang mga kopya sa PSA security paper ay ini-isyu ng [Philippine Statistics Authority](https://psa.gov.ph/).

---

## Sino ang maaaring humiling ng kopya

Ang may-ari ng dokumento, o ang asawa, mga anak, mga magulang, mga kapatid na lalaki, mga kapatid na babae, mga lolo at lola o tagapag-alaga (guardian) ng may-ari, o sinumang ibang taong pinahintulutan ng batas o ng may-ari. Inuuri ng charter ang serbisyo bilang **Simple** (Government to Client).

---

## Ano ang dadalhin

Pinupunan ng lahat ang application form. Idagdag ang patunay ng inyong kaugnayan sa rekord:

| Sino ang humihiling                                                                                                                                                | Ano ang dadalhin                                                                                                                                                                                                                                                                                                                                   |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Ang may-ari ng dokumento                                                                                                                                           | Valid ID                                                                                                                                                                                                                                                                                                                                           |
| Asawa (para sa rekord ng asawang lalaki o asawang babae at ng kanilang mga anak)                                                                                   | Application form; valid na ID na inisyu ng pamahalaan                                                                                                                                                                                                                                                                                              |
| Magulang (para sa rekord ng anak, kung nakapangalan dito bilang ama o ina)                                                                                         | Application form; valid na ID na inisyu ng pamahalaan ng may-ari ng dokumento kung nasa hustong gulang, o ng mga magulang kung menor de edad                                                                                                                                                                                                       |
| Tagapag-alagang itinalaga ng hukuman, o taong gumaganap ng substitute parental authority sa ilalim ng Article 216 ng Family Code (para sa rekord ng menor de edad) | Application form; valid na ID na inisyu ng pamahalaan; court decree ng guardianship, kung naaangkop                                                                                                                                                                                                                                                |
| Institusyong legal na nangangalaga sa menor de edad                                                                                                                | Application form; liham ng pahintulot mula sa DSWD para sa batang iyon, inisyu ng DSWD Regional Director sa Child Caring Agency                                                                                                                                                                                                                    |
| Hukuman o kaukulang pampublikong opisyal, para sa administratibo, hudisyal o iba pang opisyal na paglilitis                                                        | Application form; Subpoena Duces Tecum and Ad Testificandum                                                                                                                                                                                                                                                                                        |
| Ahensya ng pamahalaan, sa pagtupad ng mandato nito                                                                                                                 | Application form; Data Sharing Agreement sa ilalim ng NPC Circular 16-02                                                                                                                                                                                                                                                                           |
| Pinakamalapit na kamag-anak ng namatay                                                                                                                             | Application form; Affidavit of Kinship na nagsasaad na kayo ang pinakamalapit na nabubuhay na kamag-anak                                                                                                                                                                                                                                           |
| Ibang taong pinahintulutan ng may-ari o ng taong may karapatan sa rekord                                                                                           | Application form; nakasulat na pahintulot mula sa may-ari (o sa mga magulang kung menor de edad) kasama ng isang ID na inisyu ng pamahalaan ng may-ari at isa ng kinatawan. Tinatanggap ang scanned na larawan ng nilagdaang pahintulot kung tumutugma ang lagda sa ID. Kung nasa ibang bansa ang may-ari, idagdag ang kopya ng kanilang pasaporte |
